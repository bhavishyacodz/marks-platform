# MARKS Platform

A separate, mobile-first JEE Main practice platform.

## Stage 1
- Mobile dashboard
- Physics, Chemistry, and Mathematics subject tabs
- Chapter search and progress indicators
- Interactive demo question with answer checking and explanation
- Demo content is clearly labelled and is not presented as an official PYQ

## Stack
- Next.js App Router
- React
- TypeScript
- CSS

## Run locally
Use Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js (usually http://localhost:3000).

## Roadmap
1. Foundation and dashboard
2. Chapter/topic navigation and filters
3. Question engine, maths rendering, diagrams, and explanations
4. Practice sessions and progress saving
5. Backend, database, and question-review admin
6. Deployment and PWA support
