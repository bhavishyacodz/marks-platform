# JEE Main Source Papers

Upload source question-paper PDFs for the MARKS question bank in this folder when possible.

## Naming format

`jee-main-YYYY-MM-DD-shift-N-paper-1.pdf`

Example: `jee-main-2026-04-02-shift-2-paper-1.pdf`

## Verification rules

- Record the exam date, shift, session, and paper type.
- Keep questions marked unverified until checked against a reliable answer key.
- Do not upload candidate personal details or private response sheets.
- Respect the source website's copyright and terms; use source links and only store files you are permitted to redistribute.
